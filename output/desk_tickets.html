4. Three new problems this agent team could solve with the tools you built

  1. Rush of orders during orientation: same path as 101 and 103: get_ticket, get_stock, get_pricing, draft a reply with Jervis, human approve if anything needs ordering.
  2. Shop closure from rain, flood or earthquake: tickets come in like the open ones on the board, agents read them with get_ticket and reply with what stock is still on the shelves.
  3. Rent payment apps go bust or mail isn't working: the landlord sends a rent_notice like ticket 102, Father pulls the lease, Ama checks cash, human approves, pay_rent runs.

5. Three new problems this team could not solve, and what you'd need

  1. Directing where to place stock at the supplier: right now order_stock only pays and notes lead_days. We don't tell the vendor a warehouse or storage unit. Would need a tool that sends the put-away location to the vendor, and maybe a receiving agent that owns it.
  2. Updating customers when a shipment will actually arrive: we have lead_days from list_vendors but no email or SMS tool. Would need a notify_customer tool and Jervis (or a new agent) allowed to send it, instead of the Boss sending it out each time.
  3. Auto-updating inventory spreadsheets: inventory only moves when someone runs tools by hand. Would need a tool that watches a folder for a new spreadsheet and writes into the inventory table.
